Data Cleaning and Preprocessing

This stage prepares raw hyperspectral, RGB, and depth images so the data can be used for feature extraction, visualization, and modeling preparation.

Preprocessing Goal

The main goal of preprocessing was to turn raw image folders into clean, structured datasets. This included removing invalid samples, keeping usable imaging conditions, isolating plant regions, and creating CSV files that could be used later in feature engineering and analysis.

Hyperspectral Calibration Cycle Preprocessing

The calibration cycle preprocessing work focused on raw hyperspectral TIFF files. The pipeline extracted the image files, built a dataset index, sorted images by date and sequence, and checked whether each cube had the expected 51 bands.

File Extraction

Raw zipped hyperspectral files were extracted into working folders so each TIFF image could be processed individually.

Index Creation

The notebook created CSV index files to track filenames, dates, sequence order, and valid image lists.

Band Validation

Only valid 51 band hyperspectral cubes were kept. Non 51 band files were removed from the clean dataset.

NDVI Masking

NDVI based thresholding was used to separate plant pixels from background pixels and create plant masks.

The calibration cycle notebook started with 643 TIFF files, kept 492 valid 51 band images, and removed 151 files that did not match the expected band count.

Hyperspectral Quality Control Exploration

A separate exploration notebook checked a larger hyperspectral folder to understand image quality and filtering needs before feature extraction. This helped identify which images were actually usable under grow light conditions.

  • Loaded 5,829 hyperspectral TIFF images for inspection.
  • Separated usable light on cubes from lights off images.
  • Identified CAI or index cubes, bad cubes, and unknown cube types.
  • Checked duplicate captures from the same date and hour.
  • Validated cube types such as reflectance, reflectance percent, and radiance or intensity.
  • Trimmed unstable edge bands and tested spectral smoothing.
  • Confirmed that plant masks matched the spatial dimensions of the cleaned cubes.

Full Plant Cycle Hyperspectral Preprocessing

The January drought cycle pipeline filtered images by date and time, loaded 51 band TIFF cubes, calculated quality metrics, and removed frames that were outside the grow light window or did not pass quality checks.

  • Date range was filtered from January 10 to January 30.
  • The main processing window was 6 AM to 1 PM to match the grow light schedule.
  • Signal to noise ratio was calculated for quality control.
  • Plant coverage was calculated from the NDVI mask.
  • Corrupted frames and unstable frames were filtered out.

This workflow checked 293 TIFF files, processed 204 frames, kept 195 valid frames, filtered out 89 frames, and marked 9 frames as corrupted.

RealSense RGB and Depth Preprocessing

The RealSense notebook prepared RGB and depth image pairs for visible growth analysis. The first step was separating files into useful image types and removing dud images.

Image Type Separation

Files were sorted into true RGB images, raw depth images, colorized depth images, dud images, and other files.

Timestamp Matching

RGB and raw depth files were matched by year, month, day, hour, and minute so each pair represented the same capture time.

Set Separation

The RealSense data was split into Set 1 and Set 2. Set 2 was used because it had cleaner data for feature extraction.

Background Modeling

A median background image was built from RGB frames so plant regions could be separated from the chamber background.

Plant Masking

Plant masks were created differently for each sensor type. Hyperspectral images used NDVI based masks. RealSense RGB images used background comparison, pot detection, plant region separation, and largest component filtering.

  • Hyperspectral masks isolated plant pixels using NDVI thresholds.
  • Morphological cleaning improved mask quality by removing small noisy regions.
  • RealSense masks detected the two pot regions and split the image into Plant A and Plant B.
  • Mask debugging plots compared the original image, binary mask, overlay, and masked plant image.

Preprocessing Outputs

  • Cleaned hyperspectral image folder with valid 51 band TIFF files.
  • Dataset index CSV files sorted by date and sequence.
  • Metadata CSV files with basic NDVI and mask statistics.
  • Matched RGB and depth image pairs for RealSense analysis.
  • Clean plant masks for later feature extraction.
