Output and Visualization

This page presents the final visualization outputs from the Astro Cultivators project, including the RealSense dashboard and hyperspectral temporal index trends.

Final Output Overview

The output system was designed to make the pipeline easier to understand visually. Instead of only showing raw data or CSV files, the page connects image outputs, extracted features, stress detection results, and hyperspectral trends in interactive views.

RealSense Dashboard

Shows daily stress detection outputs using RGB frames, segmentation overlays, confidence values, VARI trends, and canopy area trends.

Hyperspectral Trends

Shows temporal changes in hyperspectral vegetation indices, including VOG1 and NDVI values across selected dates.

Feature Outputs

Visualizes extracted features, daily summaries, segmentation outputs, model confidence, and plant health related trends.
