Output and Visualization

This page summarizes the visual outputs created from the hyperspectral and RealSense pipelines.

Visualization Goal

Visualization helps confirm that preprocessing and feature extraction are working correctly. It also makes the results easier to explain to biology collaborators, project reviewers, and future team members.

Hyperspectral Visualizations

The hyperspectral notebook created a set of visual outputs using reconstructed color images, NDVI maps, plant masks, spectral plots, temporal patterns, and feature summaries.

RGB Reconstruction

Selected hyperspectral bands were combined to create an RGB like view of the plant image.

NDVI Map

NDVI values were displayed as heatmaps to show vegetation response across the image.

Segmentation Overlay

Plant masks were overlaid on images to check whether the plant region was isolated correctly.

False Color Composite

False color images helped highlight spectral differences that are not visible in normal RGB images.

Spectral and Feature Plots

The notebooks also created plots that summarize spectral values and vegetation features. These plots are useful for checking whether features follow reasonable patterns.

Spectral Signatures

Average reflectance curves were plotted for plant pixels and background pixels to compare spectral behavior.

Temporal Heatmaps

Feature values were visualized across dates to highlight changes over the plant cycle.

Trend Lines

Vegetation index trends were plotted to show how features changed over time.

Correlation Matrix

Feature relationships were visualized to understand which vegetation indices moved together.

RealSense Visualizations

The RealSense notebook included visualization tools for debugging plant masks and checking visible growth trends. These outputs helped verify that Plant A and Plant B were separated correctly.

Median Background

A median background image was visualized to confirm that the background model represented the empty chamber scene.

Mask Debugging

The notebook displayed the original RGB image, binary mask, green overlay, and masked only plant image.

VARI Over Time

Daily average VARI was plotted for each plant to compare visible greenness trends.

Height Over Time

Daily average height was plotted from depth exploration, with the note that height values were still noisy.

Final Output Files

The visual outputs support the CSV feature files and help explain what the numbers mean. The main output files from the notebooks include vegetation index CSV files, RealSense feature CSV files, metadata files, and plots for presentation or project documentation.

Important outputs include vegetation_indices_HS.csv, vegetation_indices_mean.csv, features_set2.csv, metadata_basic.csv, images_perday.csv, and images_permonth.csv.

Why Visualization Matters

  • It confirms that masks are selecting plant pixels instead of background.
  • It shows whether vegetation indices are changing across time.
  • It helps explain the dataset to non technical collaborators.
  • It supports future model evaluation by connecting predictions back to visual plant changes.
