Output and Visualization

This page summarizes the visual outputs, dashboards, charts, overlays, and model result views created from the project pipeline.

Visualization Goal

Visualization helped the team confirm that segmentation, feature extraction, modeling, and temporal analysis were working correctly. It also made the results easier to explain to the biology team and project reviewers.

Segmentation Visualizations

The RealSense pipeline created visual checks for Grounded SAM 2 and SAM 2.1 segmentation.

Original RGB Image

Shows the raw chamber image before segmentation.

Segmentation Mask

Shows the detected plant mask generated by SAM 2.1.

Green Overlay

Places the mask over the original image to verify plant coverage.

Separated Plants

Shows control and drought plants separated by detection box center.

Modeling Visualizations

The modeling notebook created charts and outputs to evaluate the MLP classifier and compare control versus drought predictions.

Confusion Matrix

Shows how many control and drought frames were classified correctly or missed.

ROC Curve

Shows model discrimination performance with AUC of 0.994.

SHAP Plot

Shows feature importance, including area change and early VARI standard deviation.

Onset Results

Shows the detected stress onset day and corrected p value.

Temporal Visualizations

Time series plots were used to compare plant features across monitoring days.

VARI Over Time

Compares control and drought greenness trends across days.

Area Over Time

Compares canopy area growth between treatments.

Height Over Time

Tracks vertical plant span over time.

Depth Feature Trends

Plots canopy volume, surface roughness, depth standard deviation, and related 3D structure features.

Interactive Dashboard

The output and visualization work also included an interactive dashboard for plant monitoring. The dashboard integrated RealSense trait CSVs and HS vegetation index data with multiple chart views and a filterable data table.

Dashboard Layout

Main React dashboard structure for viewing plant monitoring outputs.

Area Charts

Canopy area over time and control versus drought comparison.

Statistics Cards

Summary cards for quick interpretation of important feature values.

Data Table

Filterable table for inspecting detailed feature records.

Final Outputs

  • RealSense trait CSVs with per frame and daily aggregated features.
  • HS vegetation index CSVs.
  • MLP classification metrics and confusion matrix.
  • Stress onset detection result.
  • React dashboard components for plant monitoring.

Dashboard components included Dashboard.jsx, AreaBoundingCharts.jsx, CentroidConfidenceCharts.jsx, SideComparisonCharts.jsx, StatsCards.jsx, and DataTable.jsx.
