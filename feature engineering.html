Feature Engineering

This stage converts cleaned plant images into measurable features that describe plant health, color, structure, and growth over time.

Feature Engineering Goal

After preprocessing, the cleaned images were used to extract numerical features. These features make the image data easier to compare across time and easier to use for future machine learning models.

Hyperspectral Vegetation Features

The hyperspectral feature engineering notebooks calculated vegetation indices from wavelength bands. These indices summarize plant reflectance patterns and help show possible stress related changes.

Feature Meaning Why It Helps
NDVI Normalized Difference Vegetation Index Measures green vegetation strength using red and near infrared bands.
GNDVI Green Normalized Difference Vegetation Index Uses green and near infrared bands to capture plant greenness and chlorophyll related response.
RE NDVI Red Edge NDVI Uses red edge information, which can be useful for detecting plant stress and chlorophyll changes.
CHL RE Chlorophyll Red Edge Estimates chlorophyll related response from red edge wavelengths.
SR Simple Ratio Compares near infrared and red response as a simple vegetation strength feature.
SIPI Structure Insensitive Pigment Index Summarizes pigment related changes that may connect to stress response.
PRI Photochemical Reflectance Index Captures light use and photosynthetic related changes from selected wavelength bands.

Calibration Cycle HS Feature Work

The calibration cycle feature notebook used 51 band hyperspectral images mapped from about 450 to 850 nm. Key bands were selected for red, green, blue, near infrared, and PRI wavelengths.

Band Mapping

Target wavelengths were matched to the closest available hyperspectral band so each vegetation index could be computed consistently.

Image Level Aggregation

Vegetation index images were summarized into mean feature values for each image.

CSV Output

The output feature table was saved as vegetation_indices_mean.csv with one row per processed image.

This feature engineering step found 281 TIFF files, processed 280 valid images, and skipped one corrupted image.

January HS Feature Work

The January hyperspectral pipeline calculated five main vegetation indices and additional quality features. The output CSV included timestamp, date, time, NDVI, GNDVI, red edge NDVI, chlorophyll red edge, simple ratio, coverage, and signal to noise ratio.

Coverage

Coverage estimates how much of the image is identified as plant region after segmentation.

SNR

Signal to noise ratio was used as a quality feature to help filter unstable frames.

Time Features

Date and time were kept with each feature row so trends could be analyzed later.

RealSense RGB and Depth Features

The RealSense notebook extracted plant level features from Set 2, which was selected because it was cleaner. The image was separated into Plant A and Plant B so each plant could be tracked separately.

Area

Area was calculated from the number of plant mask pixels and used as a visible growth measurement.

VARI Median

VARI was calculated from RGB channels to estimate visible greenness while reducing some lighting effects.

Height Pixels

Depth data was explored to estimate plant height in pixels, but the notebook notes that the height values were still noisy.

Plant Label

Each feature row kept the plant label so Plant A and Plant B could be compared across time.

The RealSense feature output was saved as features_set2.csv and included date, plant label, area, VARI median, and height related measurements.

Feature Outputs

  • vegetation_indices_mean.csv for calibration cycle hyperspectral vegetation index means.
  • vegetation_indices_HS.csv for January hyperspectral vegetation indices, coverage, and SNR.
  • features_set2.csv for RealSense plant area, VARI, and height features.
