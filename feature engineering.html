Feature Engineering

This stage converts segmented plant images into measurable features for growth analysis, stress detection, and visualization.

Feature Engineering Goal

The goal was to summarize each plant image using numerical traits. These features are easier to compare over time and can be used as inputs for machine learning models.

Hyperspectral Features

The HS pipeline calculated vegetation indices from masked plant pixels. These features describe spectral plant response and can support future fusion with RGB and depth features.

NDVI

Computed from near infrared and red bands to measure vegetation strength.

GNDVI

Computed from near infrared and green bands to capture greenness and chlorophyll related response.

RE NDVI

Uses red edge wavelengths to capture stress and chlorophyll related changes.

CHL RE

Uses near infrared and red edge bands to estimate chlorophyll related response.

SR

Simple ratio of near infrared to red reflectance.

The HS Set 1 feature workflow generated 204 timestamped records across 21 days from January 10 to January 30, 2026.

RealSense RGB Mask Features

For each segmented plant, the RealSense pipeline extracted visible plant traits from the RGB image and plant mask.

Area

Area was calculated as the number of plant mask pixels.

Height

Height was estimated from the vertical span of the plant mask.

VARI Mean

VARI was computed per plant pixel and clipped to the range from negative 1 to positive 1.

VARI Standard Deviation

VARI standard deviation measured variation in visible greenness within each plant mask.

Compactness

Compactness was computed from plant area and bounding box shape.

RealSense Depth Features

The RealSense depth pipeline used the 16 bit raw depth image inside the plant mask to extract structure based features.

Depth Standard Deviation

Measures depth variation inside the plant mask and represents 3D structure complexity.

Surface Roughness

Uses depth gradients to estimate plant surface texture and structure.

Canopy Volume

Uses depth values as a proxy for canopy structure and volume.

Vertical Spread

Measures how much the plant region spreads vertically in the frame.

Baseline Normalization and Daily Aggregation

After extracting frame level features, the notebook performed baseline normalization and daily aggregation. This made the features more useful for comparing control and drought plants over time.

  • area_change = area_px minus the day 1 median for that treatment.
  • height_change = height_px minus the day 1 median for that treatment.
  • vari_change = vari_mean minus the day 1 median for that treatment.
  • Daily aggregation used median, standard deviation, and change features per date.

The RealSense pipeline produced 265 per frame rows and aggregated them into 20 daily rows for modeling and temporal analysis.

Feature Outputs

  • HS vegetation index feature tables.
  • RealSense per frame feature CSVs.
  • Daily trait CSVs with control and drought features.
  • Baseline normalized change features for model training.
