Temporal Growth Analysis

This stage tracks plant traits over time to compare control and drought trends and identify early stress onset.

Temporal Goal

The temporal analysis looks at how plant traits change across days instead of only studying one image at a time. This helps detect whether drought plants begin changing earlier than visible symptoms suggest.

RealSense Daily Trends

RealSense frame level features were aggregated by date and treatment. The final analysis focused on daily trends for VARI, area, height, and normalized change features.

VARI Trend

Tracks visible greenness over time for control and drought plants.

Area Trend

Tracks plant mask area and growth difference between treatments.

Height Trend

Tracks plant vertical span after baseline normalization.

Depth Trend

Tracks canopy volume, surface roughness, and depth variation for plant structure analysis.

Stress Onset Detection

The notebook used daily statistical testing to detect when drought plants first became significantly different from control plants. The main onset test used VARI change with a weighted t test and Benjamini Hochberg correction.

Hyperspectral Temporal Features

The HS feature workflow also supports temporal analysis because each feature row keeps its timestamp. HS outputs include daily vegetation index trends for NDVI, GNDVI, red edge NDVI, chlorophyll red edge, and simple ratio.

  • HS Set 1 covered January 10 to January 30, 2026.
  • The HS feature workflow produced 204 timestamped records across 21 days.
  • Future work can fuse HS vegetation indices with RealSense model features.

Interpretation

The temporal results show that feature trends can reveal stress earlier than simple visual inspection. In the final model analysis, stress was detected at day 2 before clear visible symptoms.

The current limitation is that Set 2 contained only 2 plant pairs and one temperature condition, so the onset result should be validated on additional experiments.
