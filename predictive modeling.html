Predictive Modeling

This page describes how the extracted features prepare the project for plant stress classification and growth trait prediction.

Modeling Status

The notebooks currently focus mainly on data preprocessing, feature engineering, temporal analysis, and visualization. The modeling stage is prepared around the feature tables created from hyperspectral and RealSense data. Final model performance metrics should be added after the model training notebooks are completed and reviewed.

This page does not claim final accuracy, F1 score, or prediction results yet. It explains the modeling inputs and planned modeling direction based on the current pipeline.

Modeling Inputs

The project creates structured feature tables that can be used as model inputs. These tables are easier to train on than raw images because each row summarizes plant information at one image time point.

Hyperspectral Features

NDVI, GNDVI, red edge NDVI, chlorophyll red edge, simple ratio, SIPI, PRI, coverage, and SNR can be used as spectral plant health features.

RealSense Features

Area, VARI median, and height related features can be used to model visible plant growth and stress related changes.

Temporal Features

Date, time, daily averages, and feature changes over time can help models learn growth patterns instead of only single image values.

Stress Classification

The main classification goal is to predict plant stress condition, such as control versus drought, using extracted features. For RealSense Set 2, Plant A and Plant B can be tracked separately, which supports comparison between plant groups across time.

  • Possible input features include vegetation indices, VARI, area, and height.
  • Possible labels include control and drought treatment labels from the experiment design.
  • Models can start with simple classifiers before moving to deeper models.
  • Feature based models are useful as a baseline before raw image deep learning.

Trait Regression

Besides classification, the project can also use regression models to predict continuous plant traits. These traits may include growth measurements such as plant area, height, or vegetation index trends.

Area Prediction

Plant mask area can be predicted or tracked as a growth trait.

Height Prediction

Depth based height is still noisy, but it can become a useful regression target after refinement.

Vegetation Index Trends

Models can predict or compare NDVI, GNDVI, PRI, and VARI changes over time.

Evaluation Metrics

Once the modeling notebooks are finalized, the project can evaluate stress classification and regression tasks with standard metrics.

  • Classification metrics: accuracy, precision, recall, F1 score, and confusion matrix.
  • Regression metrics: MAE, RMSE, and R squared.
  • Temporal evaluation: trend consistency, early stress detection timing, and comparison between control and drought plants.

Expected Outputs

  • Clean model input CSV files.
  • Baseline stress classification models.
  • Regression models for growth traits.
  • Model evaluation tables and plots.
  • Visual comparison between predicted and observed plant trends.
