Predictive Modeling

This stage uses RealSense RGB and depth features to classify soybean plants as control or drought stressed.

Modeling Goal

The modeling goal was to detect drought stress before visible symptoms were obvious. The input data came from RealSense Set 2, using extracted plant traits from RGB masks and 16 bit raw depth images.

This page is based on the final RealSense pipeline, where the team benchmarked multiple classifiers and selected an MLP model for stress classification.

Modeling Dataset

The model used Set 2 Williams 82 soybean data collected under controlled chamber conditions. The experiment used a 28°C and 26°C day night temperature setting with a 7 hour photoperiod.

Input Features

The model used baseline normalized change features so control and drought plants could be compared more fairly across time.

Variation in pixel level greenness within the plant mask.

Height Change

Models Tested

The modeling notebook benchmarked 12 classifiers using leave one day out cross validation. Each fold held out one date as the test set, which made the evaluation more strict for temporal data.

Final MLP Model

The final reported model was an MLP with two hidden layers. The four input features were scaled using StandardScaler inside each cross validation fold.

Architecture

Input layer with 4 features, then 64 neurons, then 32 neurons, then a binary output.

Training Setup

scikit learn MLPClassifier with max iteration set to 1000.

Validation

Leave one day out cross validation, where each day was held out once as the test set.

Results

The MLP classifier performed strongly on Set 2. The model missed 2 out of 265 frames and detected stress onset at day 2.

Feature Importance and Onset Detection

SHAP analysis was used to understand feature importance. Area change dominated across the full timeline, while VARI standard deviation was most useful in the earliest days. Onset detection used per day weighted t tests on VARI change with Benjamini Hochberg correction.

The onset rule was the first significant day where drought VARI dropped below control. The final result showed stress onset at day 2 with corrected p value of 0.031.

Limitations

  • The final model was tested on 2 plant pairs only.
  • Only one temperature condition was tested.
  • Future work should validate the model on more plant sets, light settings, and temperature conditions.
  • Hyperspectral features were not fully fused into the final classifier yet.
