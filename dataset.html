Dataset

The Astro Cultivators dataset combines hyperspectral, RGB, and depth imaging to monitor soybean growth and drought stress in controlled chamber experiments.

Dataset Overview

The project uses multiple imaging sources so plant health can be studied from more than one view. Hyperspectral images capture wavelength based plant response, RGB images capture visible color and shape, and depth images support structure and height related measurements.

Imaging Modalities

Hyperspectral Images

Hyperspectral TIFF cubes were used to measure plant response across many wavelength bands. These images support vegetation indices such as NDVI, GNDVI, SIPI, PRI, red edge NDVI, chlorophyll red edge, and simple ratio.

RGB Images

RGB images from the RealSense camera were used to segment visible plant regions, compare plants against a median background, and compute visible growth features such as area and VARI.

Depth Images

Depth images were matched with RGB frames by timestamp. These images were used to explore height related plant measurements and 3D structure information.

Experiment Sets

The dataset includes calibration work and drought stress experiments. The experiment log includes chamber settings, sensor use, watering schedules, plant dates, and notes about data quality.

Hyperspectral Dataset Details

The calibration cycle preprocessing notebook started with 643 hyperspectral TIFF files. After checking the cube dimensions, 492 valid 51 band images were kept and 151 non 51 band files were removed. A later feature engineering step processed 280 valid images and skipped one corrupted file.

Another exploratory notebook inspected a larger hyperspectral folder with 5,829 TIFF files. That exploration separated usable light on cubes, CAI or index cubes, bad or unknown cubes, and lights off images. This helped the team understand data quality before final feature extraction.

RealSense Dataset Details

The RealSense workflow separated image files into true RGB images, raw depth images, colorized depth images, and unusable dud images. RGB and raw depth files were matched by timestamp, then filtered to the grow light window.

The RealSense data was also divided into Set 1 and Set 2. Set 1 covered the first growth session ending on January 30, and Set 2 began later on January 30. Set 2 was selected for cleaner feature extraction.

Dataset Limitations

  • Some files were removed because they were lights off images, unreadable, corrupted, or not valid 51 band cubes.
  • Some hyperspectral data could not reliably separate control and drought plants by file alone, so those notebooks focused on overall vegetation metrics.
  • RealSense height features were exploratory because the depth based height values were noisy and still needed refinement.
  • Some experiment log dates and notes may need final team review before being treated as final audited metadata.

Data Infrastructure

The notebooks use Python, NumPy, Pandas, tifffile, OpenCV, Matplotlib, SciPy, and scikit image to organize files, load images, filter invalid data, calculate features, and export CSV outputs for later analysis.
